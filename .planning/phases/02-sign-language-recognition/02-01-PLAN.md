       ```python
       from pydantic import BaseModel, field_validator
       from typing import Optional, List

       class Landmark(BaseModel):
           x: float
           y: float
           z: float
           visibility: float

           @field_validator('x', 'y', 'z')
           @classmethod
           def check_normalized(cls, v):
               if not 0 <= v <= 1:
                   raise ValueError('Coordinates must be normalized [0,1]')
               return v

       class HandLandmarks(BaseModel):
           handedness: str  # 'Left' or 'Right'
           landmarks: List[Landmark]

           @field_validator('landmarks')
           @classmethod
           def check_21_points(cls, v):
               if len(v) != 21:
                   raise ValueError('Expected 21 landmarks')
               return v

       class LandmarksPayload(BaseModel):
           landmarks: dict  # {'left': HandLandmarks, 'right': HandLandmarks}
           timestamp: int
           sessionId: str
       ```

    2. `recognition-service/app/schemas/recognition.py`:

       ```python
       from pydantic import BaseModel

           text: str

       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client→Socket.io | Untrusted landmark payloads from any connected client |
| Socket.io→Classifier | Processed data fed to ML model (potential adversarial inputs) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | Socket.io connection | mitigate | Verify JWT on connect using shared secret with Node.js API (D-02); reject unauthenticated connections |
| T-02-02 | Tampering | Landmark payload | mitigate | Pydantic validation: check coordinate bounds [0,1], exactly 21 landmarks per hand, reasonable frame rate (<100ms between timestamps) |
| T-02-03 | Denial of Service | Large payloads | mitigate | Limit payload size to 10KB per landmark message; rate limit per sessionId (max 30 fps) |
| T-02-04 | Information Disclosure | Recognition logs | accept | Logs may contain session IDs but no PII; no sensitive data at rest; transit encryption via HTTPS/WSS in production |
| T-02-05 | Elevation of Privilege | Model file access | accept | Container runs as non-root user (app user); model files read-only; compromise would require container breakout |

</threat_model>
