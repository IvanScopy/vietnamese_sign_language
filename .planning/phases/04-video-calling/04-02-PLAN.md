    Create the following API route handlers. All routes must extract the authenticated userId from the JWT token using the project's existing auth utility (grep for getUserIdFromToken or similar pattern in src/app/api/).

    1. POST /api/calls (src/app/api/calls/route.ts):
       - Extract callerId from JWT auth
       - Parse and validate body with CreateCallSchema (calleeId required)
       - If callerId === calleeId, return 400
       - Call checkBusy(calleeId); if true, return 409 { error: 'User is busy' }
       - Call checkBusy(callerId); if true, return 409 { error: 'You are already in a call' }
       - Call createCall(callerId, calleeId)
       - Emit call:incoming to callee via emitCallEvent('call:incoming', calleeId, { callId, fromUserId: callerId, expiresAt, type: 'VIDEO_CALL' })
       - Emit call:ringing to caller via emitCallEvent('call:ringing', callerId, { callId, roomName })
       - Call sendCallPushNotification(calleeId, callId, callerName from User.name) — fire-and-forget, do not await
       - Return 201 { callId, roomName, expiresAt }

    2. POST /api/calls/[callId]/accept (src/app/api/calls/[callId]/accept/route.ts):
       - Extract userId from JWT auth
       - Parse callId from URL params
       - Call acceptCall(callId, userId)
       - On success: emit call:accepted to caller and callee via emitCallEvent
       - Return 200 { roomName, token: calleeToken, callerToken } (callee uses calleeToken, caller receives callerToken via socket event or can call /token endpoint)
       - On failure (call unavailable): return 409 { error: 'Call unavailable' }

    3. POST /api/calls/[callId]/reject (src/app/api/calls/[callId]/reject/route.ts):
       - Extract userId from JWT auth, parse callId from URL
       - Call rejectCall(callId, userId)
       - Emit call:rejected to caller via emitCallEvent
       - Return 200 { success: true }

    4. POST /api/calls/[callId]/cancel (src/app/api/calls/[callId]/cancel/route.ts):
       - Extract userId from JWT auth, parse callId from URL
       - Call cancelCall(callId, userId)
       - Emit call:cancelled to callee via emitCallEvent
       - Return 200 { success: true }

    5. POST /api/calls/[callId]/end (src/app/api/calls/[callId]/end/route.ts):
       - Extract userId from JWT auth, parse callId from URL
       - Call endCall(callId, userId)
       - Emit call:ended to both caller and callee via emitCallEvent
       - Return 200 { success: true }

    6. POST /api/calls/[callId]/token (src/app/api/calls/[callId]/token/route.ts):
       - Extract userId from JWT auth, parse callId from URL
       - Verify call exists and state is ACTIVE, and userId is either caller or callee
       - Generate a fresh LiveKit token for this participant using generateLiveKitToken
       - Return 200 { token }
