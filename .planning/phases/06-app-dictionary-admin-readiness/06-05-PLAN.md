<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> user APIs | Auth/session state can expire or be missing. |
| Browser -> camera | User permission and media stream lifecycle must be controlled. |
| Browser admin UI -> admin APIs | UI must not be treated as authorization. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Elevation of Privilege | `/admin` UI | mitigate | Show/hide UI based on API responses, but rely on backend 401/403 from plan 06-04. |
| T-06-02 | Information Disclosure | Dictionary pages | mitigate | Consume only user dictionary APIs that filter published entries; do not call admin APIs from user pages. |
| T-06-05 | Denial of Service | `src/app/recognition/page.tsx` | mitigate | Provide explicit stop action and stop tracks on unmount. |
| T-06-11 | Information Disclosure | Web SOS/profile copy | mitigate | Present browser SOS as informational only; do not expose SOS log details on user pages. |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs no packages. |
</threat_model>
