<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public/mobile query -> dictionary APIs | User-controlled search/category params enter Prisma queries. |
| Database draft content -> user response | Unpublished dictionary rows must never cross into user-visible payloads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-02 | Information Disclosure | User dictionary APIs | mitigate | Hard-code `status = PUBLISHED` plus playable-video filter in every user query. |
| T-06-07 | Tampering | Query params | mitigate | Bound `limit`, normalize `q`, and avoid raw SQL for user search. |
| T-06-08 | Information Disclosure | Storage metadata | mitigate | Return only public CDN URLs/keys and thumbnails; never return provider secrets. |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs no packages. |
</threat_model>
