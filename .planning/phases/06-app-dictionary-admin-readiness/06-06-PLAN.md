<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile token storage -> API calls | Bearer token can expire or be missing. |
| Mobile dictionary API -> UI | User-visible client must not expose drafts even if malformed responses occur. |
| Existing SOS/call push routes -> new shell | Route changes must not break emergency/call navigation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-12 | Spoofing | `AuthService` | mitigate | Use backend login/register/refresh endpoints and treat 401 as session expired; do not invent local auth. |
| T-06-02 | Information Disclosure | `DictionaryService` | mitigate | Consume only user dictionary APIs; do not call admin endpoints or render status fields. |
| T-06-13 | Denial of Service | Mobile route migration | mitigate | Preserve existing named routes for push/call/SOS while replacing only the home shell. |
| T-06-14 | Information Disclosure | Profile UI | mitigate | Show only profile/contact fields; no passwords, tokens, provider payloads, or admin-only data. |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs only the approved official Flutter `video_player` 2.11.1 dependency from 06-RESEARCH.md; unresearched Flutter video packages are not allowed. |
</threat_model>
