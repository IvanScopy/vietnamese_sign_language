<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin request -> admin helpers | Untrusted cookies/Bearer tokens cross into privileged role checks. |
| Import manifest -> database | Untrusted seed metadata can create user-visible entries unless status rules are enforced. |
| Admin browser -> object storage | Presigned uploads must not expose provider secrets or arbitrary keys. |
| Prisma schema -> live dev DB | Schema changes can destroy local data if pushed incorrectly. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Elevation of Privilege | `requireAdminRole` | mitigate | Load the user by authenticated `userId`, require `isActive`, and compare `adminRole` against allowed role sets. |
| T-06-02 | Information Disclosure | `DictionaryEntry.status` | mitigate | Persist explicit status and require user APIs to filter to published entries with video metadata. |
| T-06-03 | Information Disclosure | `src/app/lib/storage.ts` | mitigate | Use presigned URLs and env vars; never return access keys, secret keys, bucket credentials, or provider errors to clients. |
| T-06-04 | Repudiation | `AdminAuditLog` | mitigate | Provide shared audit helper and require sensitive mutation plans to write audit rows inside transactions. |
| T-06-06 | Tampering | `scripts/import-dictionary.ts` | mitigate | Validate manifest rows with Zod, normalize search fields, and downgrade invalid rows to `NEEDS_REVIEW` or `DRAFT`. |
| T-06-SC | Tampering | npm installs | mitigate | Only install packages approved by `06-RESEARCH.md` Package Legitimacy Audit. |
</threat_model>
