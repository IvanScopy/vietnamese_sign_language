**STT/TTS Strategy:**
- Hybrid strategy pattern with cloud primary (Groq Whisper, ElevenLabs) + self-hosted fallback (Whisper.cpp, Coqui TTS)
- VieNeu-TTS noted for future research if budget constraints require fully self-hosted
- Latency target: <500ms; accuracy prioritized over open-source preference

**Authentication:**
- JWT with 15-minute access tokens + 7-day refresh tokens
- Refresh token rotation with Redis blacklist
- Multiple concurrent sessions allowed
- Email/password + Google OAuth

**Notifications:**
- Hybrid: Socket.io for in-app + FCM/APNs for background
- SOS uses high-priority/critical alerts
- Custom vibration + colors via notification payload

**Infrastructure:**
- Single VPS ($6-10/mo, cheapest global location — Singapore/EU)
- PostgreSQL + Redis on same server
- Docker Compose orchestration
- LiveKit self-hosted for WebRTC

**API:**
- Monolithic REST with `/api/v1/` prefix
- OpenAPI codegen for TypeScript types
- Shared API for mobile and web (no BFF)
