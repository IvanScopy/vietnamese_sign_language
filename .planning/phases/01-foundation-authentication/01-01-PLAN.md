  <action>
    Create `prisma/schema.prisma` with the User and RefreshToken models per CONTEXT.md (JWT stateless auth with refresh tokens) and RESEARCH.md verified pattern:
    
    ```prisma
    generator client {
      provider = "prisma-client-js"
    }
    
    datasource db {
      provider = "postgresql"
      url      = env("DATABASE_URL")
    }
    
    model User {
      id           Int       @id @default(autoincrement())
      email        String    @unique
      password     String    // bcrypt hash
      name         String?
      userType     UserType  @default(HEARING)
      createdAt    DateTime  @default(now())
      updatedAt    DateTime  @updatedAt
    
      // Relations
      refreshTokens RefreshToken[]
    
      @@map("users")
    }
    
    model RefreshToken {
      id        Int      @id @default(autoincrement())
      token     String   @unique
      expiresAt DateTime
      userId    Int
      user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)
      createdAt DateTime @default(now())
    
      @@index([userId])
      @@map("refresh_tokens")
    }
    
    enum UserType {
      DEAF
      HEARING
    }
    ```
    
    Create `src/app/lib/db.ts` with Prisma Client singleton per RESEARCH.md Pattern (lines 312-324) to prevent multiple instances in development:
    
    ```typescript
    import { PrismaClient } from '@prisma/client'
    
    const globalForPrisma = globalThis as unknown as {
      prisma: PrismaClient | undefined
    }
    
    export const prisma = globalForPrisma.prisma ?? new PrismaClient()
    
    if (process.env.NODE_ENV !== 'production') globalForPrisma.prisma = prisma
    ```
    
    Run `npx prisma init --datasource-provider postgresql` if schema doesn't exist yet, then:
    Run `npx prisma migrate dev --name init` to create the initial migration and database.
    
    Run `npx prisma generate` to generate the Prisma Client.

| Boundary | Description |
|----------|-------------|
| Client → API | Untrusted input from web and mobile clients |
| API → Database | Internal boundary, trusted |
| API → External STT/TTS | External API keys, untrusted responses |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | S | docker-compose.yml | accept | Internal VPS deployment, no external access to DB/Redis directly |
| T-01-02 | T | prisma/schema.prisma | mitigate | Prisma uses parameterized queries; no raw SQL; prevents SQL injection |
| T-01-03 | I | .env file | mitigate | .env must be in .gitignore; secrets never committed; use .env.example for documentation |
| T-01-04 | D | postgres service | mitigate | Strong password in env vars; no external port exposure in production (remove 5432:5432 port mapping for prod) |
